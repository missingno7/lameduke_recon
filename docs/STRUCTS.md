# LameDuke data structure and access audit

All 554 oracle operands flagged in the levers audit have an attribution. The two input sets are 281 typed-binding misses and 273 unanchored memory operands across 42 NEAR functions at levers revision `8c1de60`. The ledger has one row per operand, including both sides of a string instruction when both were flagged. It records the object coordinate, machine width, operation, effective object or pointee, and the evidence for sign and use. Addresses are hexadecimal. Widths and counts are decimal. [Site ledger](attributions.tsv)

A relocated instruction displacement can point before an array when the index register was already incremented. The six apparent viewport-variable references in the gap set all access `lwall[]`. A separate pass found 33 incorrect labels among already typed rows, including 11 apparent `msy` operands that actually use `tempbuf`. These are attribution errors in the levers report. The canonical symbol bases agree with the original uses. [Additional corrected rows](catalog-corrections.tsv)

The map comparison uses the dated October 17, 1994 donor `external/x/kenbuild-20260331/kenbuild-related-archives-20260331/build_1994_10_17_partial/BUILD.H`, plus `loadboard` and `saveboard`. In particular, the signed wall-index conversion inside `moveeffectors` can come from a cast or assignment of the unsigned field. The previous DOS audit changed the declared fields to signed and lost 2 SECTOR and 15 ENGINE STRICT functions. Its unsigned sprite-owner control lost the 1,364-byte `animatesprites` proof and four ACTORS proofs. Keep both historically attested declarations. [Levers controls](../levers/NOTES.md)

The additional catalogue corrections use the same effective-address arithmetic. For example, `1:3c850` loads `startumost[x-1]` and `1:3c857` stores `umost[x-1]`. The adjacent pair reads `startdmost[x-1]` and writes `dmost[x-1]`. The debiased bases are `2:13b010`, `2:bbb90`, `2:13a610`, and `2:bb190`. The matched `setview` initialization independently confirms the two starting bounds. Similar checks recover `lastx`, `sqrtable`, `palookup`, `thesprite`, and `tempbuf`, including in STRICT controls. For future census runs, normalize indexed displacements using their induction-variable bias before applying nearest-symbol rules. Source-binding overlays are unnecessary here.

## DOS tests

Each trial compiled full translation units serially with hash-pinned Watcom 9.5 GA (`wc95b`) under DOSBox-X through `tools/wcc.py`, with the registered include search and flags. The results use the unmodified `match.verify_object` verifier. `blockdiff` measures NEAR agreement only. Results are against current reconstruction TUs, while the attribution table follows the original levers audit. The intervening PLAYER operand-order change at `64c9ac2` reproduces the same DOS object.
