# Ken Silverman's C idioms in early Build

This catalogue tracks source forms that can help reconstruct the December 1994 Build code in LameDuke. **ATTESTED** means the spelling occurs in the cited source. **PROVEN** means the stated code-generation result was observed in a scoped compile or the repository's STRICT result. Historical wording, authorship and optimizer behavior are separate claims. Compare a nearby donor and the oracle before changing the current reconstruction.

## Idioms

| # | Source habit and dated evidence | Watcom 9.5 shape or reconstruction clue |
|---|---|---|
| 1 | **Repeat an indexed endpoint lookup.** E94 `wallfront` 818–825 reads `wall[wall[thewall[l1]].point2]` separately for x and y. E95m `neartag` 5445–5505 still spells the second endpoint through the wall array. | The optimizer may merge some repeated reads. Match the ordered loads, register lifetimes and relocation references as emitted. Using the March form in `neartag` closed 110 bytes at once to make the 1,644-byte function STRICT. |
| 2 | **Use a pointer through a coherent record operation.** E95m `wallfront` 460–470 switches to `wal = &wall[...]` and advances through `wal->point2`. E96 around 373 advances both index and wall pointer in the `for` header. | The dated shift from indexed access to pointers is useful dating evidence. A small `&array[i]` temporary can fold away. Across live calls or multiple field accesses a base may stay in a register. |
| 3 | **Take the live endpoint delta where it is used.** E94 `raytrace` 5304–5338 repeats `(x2-x1)` and `(y2-y1)` inline. E95 5749–5779 computes `x21, y21, x43, y43` and reuses them in a revised algorithm. | Repetition and caching can converge after common-subexpression elimination, or change the first use and register home. Preserve the period and algorithm when choosing. The April inline-delta trial in the current full TU retained its 613-byte extent and was farther from the oracle. |
| 4 | **Preserve the order of factors and terms.** G94 `processinput` 2229–2239 multiplies `(long)syncvel[snum]` by `doubvel` before multiplying the sine term. E94 `wallfront` 827–851 puts the query x delta before the edge y delta. | In signed fixed-width arithmetic, a commuted factor can still change the Watcom destination register, evaluation order and scheduling. The March `neartag` correction depended on its written dot-product order as well as repeated endpoint reads. |
| 5 | **Use coordinate-first projection with consecutive sine-table phases.** E95m `scansector` 413–421 computes `xs*cosglobalang+ys*singlobalang` then `ys*cosglobalang-xs*singlobalang`. G94 `processinput` 2229–2239 uses masked `ang+2560`, `+2048`, `+1536`. | Track shifts and scale separately from the trig identities. Multiplying coordinate by `sintable` and then shifting the accumulated term differs from independent shifts on each product. STRICT `rotatepoint` has a two-product fixed-point helper. |
| 6 | **Take absolute values where the metric is used.** G94 985 uses `labs` in sprite proximity. E95m `hitscan` at 5330 and `neartag` around 5575 use sums of `klabs` coordinate differences. | The historical `klabs` auxiliary compiles to sign test, branch over `neg`. Preserve sign and compare orientation together with the selected helper. Early snapshots also use `labs`; the name alone cannot date all call sites. |
| 7 | **Choose the fixed-point primitive by numerator width and shift.** E94 `drawalls` around 947 calls generic `mulscale(...,7)` and uses `divscale` for interpolants. E95m `grouvline` 4858–4866 uses `divscale16` and `mulscale10`. | Attested aux `scale` uses signed wide multiply and divide. Generic `mulscale` ends in `shrd ... ,cl`; a numbered variant carries the immediate. `divscale` shifts the signed wide numerator with `shld` and `shl` before `idiv`. STRICT `drawalls`, `calcwalls` and `rotatepoint` ground these choices in December. |
| 8 | **Write the relation in the donor's operand order.** E94 `scansector` 791 uses `wall[z].point2 < z`; its screen test around 803 uses `xb2[z] >= xb1[p2[z]]`. E95m 450 keeps the latter. B94 `drawline16` 1283 uses `y1 < y0` before swapping. | Compare operand width, order and fall-through together. Reversing the wall test alone in the current `scansector` preserves all seven baseline differences. Conversely, the full March screen test changes allocation and the extent. |
| 9 | **Guard at the entry, then return within special cases.** B93 `BUILD.C` 537, 588 and 726 has short `return(-1)` exits. B94 `drawline16` 1274–1296 rejects offscreen endpoints and returns after the axis-aligned fast path. E95m `wallfront` 473–489 nests a zero guard and short returns. | Read the target independently for zero, sign and branch order. Watcom can funnel short returns into a common epilogue even across functions, making extent changes visible in otherwise unedited callers. |
| 10 | **Use one inclusive wall-range convention.** E94 `scansector` 783–796 and B95/B96 640–641 form `endwall=startwall+wallnum-1` and loop with `<=`. E96 373 shows the later exclusive end and pointer stride. | An inclusive fence usually compares with `jg`/`jle` and an exclusive one with `jge`/`jl`, subject to layout and the effective index type. Recover how the end was formed before changing `<` or `<=`. |
| 11 | **Start possibly empty sprite walks before the loop.** E94 `drawalls` around 1798–1816 and B95/B96 643–647 use `i = headspritesect[...]`, `while (i != -1)`, then advance at the tail. E95m `scansector` 413 uses a top-tested `for` with `>=0`. | A `while` and equivalent `for` can compile alike. A guarded `do` can have a different topology. With December's list bounds, the top-tested `while` closed `draw2dscreen` at 3,202 B. |
| 12 | **Save the next sprite before mutation.** G94 983–985 and 1296–1304 save `nexti` before work on the current item. B94 `BUILD.C` around 2664 saves `k` before changing the list. | A load before deletion or relinking is a semantic constraint. The load must live across the work and is observable in the register saves or spill. A read-only walk can advance directly at its tail. |
| 13 | **Use a post-tested walk for known nonempty chains.** E94 `scansector` 804 uses a top-tested walk for `p2`, while the wall bunch renderer walks a known first item before following the link. December STRICT `drawrooms` and `drawalls` have this latter `do` form. | Check whether the first index is valid by construction. Replacing a `do` on a known-valid bunch can introduce a preheader test and move branch targets. |
| 14 | **Use loop indices and staging locals by role.** B95/B96 639–646 uses `j` for a wall and then a sprite index. E94 `scansector` 768 uses `short z` for wall scans and `zx` for a chain walk. G94 `sync` 3064–3090 uses `long i` for players, `j` for output position, `k` for the bit cursor. | Variable names are period evidence. Declaration grouping, type and reuse matter only insofar as they change lifetimes or Watcom's tie resolution. MULTI's `-5r` can use a word load, or a dword load plus `sar 16`, depending on context. |
| 15 | **Use grouped assignments and comma at natural cursor boundaries.** G93 `main` 35–39 clears keys in order. E94 `scansector` 772 and 803 seeds the list and advances its cursor in related assignments. M00 609 puts `ESC2` and cursor advance together. | A comma expression sequences the left action before the right. Consecutive statements sometimes lower to identical IR. December STRICT `comsend` advances in each of its arms and Watcom shares a tail. |
| 16 | **Spell byte extraction with a mask.** G94 `sync` 3103–3107 uses `&255` and `>>8` plus `&255`. E95m `screencapture` 3053–3075 and M00 `netsend` 406–419 do so for serialized fields. | A whole-register result can need explicit zero extension. A byte sink can sometimes make the mask redundant, but the ECB address and segment masks gave `netsend` 593 STRICT bytes. Retain the high-byte distinction in contexts where Ken wrote a direct shift. |
| 17 | **Reassemble bytes by adding shifted terms.** G94 `getpackets` 3168–3208 and M00 `neton` 245–248 form words/identifiers with additions and shifts. December STRICT `getpackets`, `netinitconnection` and `processreservedmessage` provide neighboring examples. | Byte load, zero/sign extension, `shl` and `add`/`lea` can produce different shapes from `or`. A C cast and a mask can select different input widths even if the destination truncates. |
| 18 | **Treat bitmaps, wrap masks and key latches as separate forms.** E95m `scansector` 433 uses `gotsector[sectnum>>3] |= 1<<(sectnum&7)`. G94 `sync` 3082–3107 uses `tempbuf[k>>3]` and `k&7`. E95m `scansector` 418 uses `(cstat&48)>0`; B96 around 652 uses `keystatus[scan]>0`. | Signed positive and nonzero tests coincide only with a proven range. Recognize `test`/conditional branch and whether the oracle discards the upper bits. Keep a ring cursor's `& (size-1)` attached to its advance, as in STRICT `comsend`. |
| 19 | **Set limits in the unit actually consumed.** E94 `screencapture` 2640 writes a 768-byte palette. E95m 3075 writes the 128-byte header and bounds runs by their row and byte budget. December's STRICT `screencapture` retains literal header/palette lengths and a next-pixel pointer. | Write-call arguments, row remainder and the RLE cap identify distinct loops. A write count is a semantic field. Keep the independently decoded widths and mode branches. |
| 20 | **Enter pointer-copy loops with explicitly established bases.** E95 `makepalookup` 7180–7189 computes the remap source and destination before the shade-row loop, then steps both by 256. E95 7197–7210 uses a byte palette pointer with a three-byte stride. | Pointer and indexed source can lower alike in small cases. Independent stride, loop nesting and aliasing determine whether a pointer survives in a register. December's RGB search has different distance logic from June's `gdist` search. |

Source line ranges identify occurrences, not mechanical rewrite rules. The reconstructed STRICT examples are from the frozen engine and MULTI baselines described in the companion report. `docs/WATCOM95_QUIRKS.md` documents broader controlled tests for switch attribution, width, shared epilogues and allocation.
## Reduced DOS compiler checks

The fixture uses the canonical `src/engine/PRAGMAS.H` and stock `tools/wcc.py`, routed into worker scratch. It compiles the same 25 publics with the registered engine, MULTI and GAME profiles. The table describes the engine fixture. `probes/listing.txt` preserves the complete disassembly, including the secondary profiles. The reduced code establishes lowering for these examples. A whole-unit result remains the test for the historical function.

| Fixture | Observed shape |
|---|---|
| `high_byte`, `high_shift`, `low_word` | `(x>>8)&255` emits `sar eax,8` then `and eax,0xff`; shift-only omits the AND. `x&65535` uses a full EAX mask. |
| `abs_local`, `abs_lib` | The aux body emits `test eax,eax; jns; neg eax`. The `labs` form is a tail jump with an external `labs_` relocation. |
| `scaled`, `scaled_mul`, `scaled_div` | `scale` emits `imul ebx; idiv ecx`; generic `mulscale(...,16)` loads ECX with 16 then uses `imul; shrd eax,edx,cl`; generic `divscale(...,16)` sign-extends the numerator with `sar edx,31`, then `shld; shl; idiv`. |
| `dot_ab`, `dot_ba` | In the register-only dot fixture the commuted products coalesce at the same public address. The shared body uses two `imul` instructions then `add`. The whole-unit `wallfront` and `drawline16` results show why this control cannot predict the contextual register decision. |
| `written_lt`, `written_gt` | The equivalent source relations emit `cmp eax,edx` / `jl`, versus `cmp edx,eax` / `jg`. The branch reaches the same `use` target. |
| `early_out`, `body_guard` | Both test EAX. The negative guard branches to a shared return, while the positive body guard conditionally transfers to `use`. Same logic, different branch topology. |
| `repeated`, `staged` | Two source reads of `point2[i]` collapse to one memory reference in the repeated-index form, with `movsx` directly from memory. Explicitly staging a short uses `mov ax,[...]` and `cwde`, then jumps to the shared indexed-load tail. |
| `list_while`, `list_for`, `list_do` | The `while` tests before the body and uses an unconditional back edge (42 B including the shared-return branch). The `for` jumps into a bottom test (45 B). The guarded `do` emits both the initial guard and loop-end test (53 B). |
| `octet_loop`, `long_loop` | In the same inclusive range, a short cursor sign-extends before indexing and compares `bx,dx`. The long cursor compares `eax,edx` and lets the increment precede a store at `eax-1`. |
| `indexed`, `pointer` | For explicit `&xs[i]` and `&ys[i]` bases, the compiler shifts the index, adds the two addresses, and loads indirectly. Direct indexing uses scaled indexed loads. Both pass x/y in the same arguments. |
| `triple`, `sum3` | `i*3` emits a shift by two followed by subtraction; `i+i+i` uses `lea` to double and then `add`. This matches the intuition behind testing the two palette-index spellings, but says nothing about the correct full palette loop. |
